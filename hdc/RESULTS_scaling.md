## 傾き実験 (d=128, 6M→24M語, 同じ評価位置 eval_seed=777, vsink=1)

| 構成 | 6M 単独 | 24M 単独 | 倍増あたり(単独) | 6M 混合 | 24M 混合 |
|---|---|---|---|---|---|
| L4 n256 | 7.2538 | 6.8067 | -0.224 | 6.0267 | 5.9369 |
| L8 n256 | 7.2371 | 6.7603 | -0.238 | 6.0240 | 5.9324 |
| L4 n512 | 7.2468 | (中止) | - | 6.0249 | - |

- 層を倍(L8)・表を倍(n512)にしても 6M 語では差が 0.02 以内。24M 語でも L8 の差は 0.047。幅方向の増やし方では傾きは変わらない。
- 混合の倍増あたりは約 -0.045〜-0.047 bit/語 (n-gram と混ぜた後は、単独の改善の大部分が n-gram に吸収される)。
- vsink: GPU の実計算 21.16 → 20.43 ミリ秒/歩 (1.035倍)。見込み (1.1〜1.25倍) は外れた。

## vfac: Val の行を共有部品の積の和にする (d=128, L4 n256, R=8, eval_seed=777)

| 構成 | 6M 単独 | 24M 単独 | 倍増あたり | 6M 混合 | 24M 混合 |
|---|---|---|---|---|---|
| 基準(全行表) | 7.2538 | 6.8067 | -0.224 | 6.0267 | 5.9369 |
| 共有部品のみ (vfac=8, vfull=0) | 7.2519 | 6.8116 | -0.220 | 6.0284 | 5.9381 |
| 全行表+共有部品 (vfull=1) | 7.2576 | 6.8019 | -0.228 | 6.0279 | 5.9320 |

- 共有部品のみは、Val の層のパラメータが約1/250 (n²=65536行 → R·n·2=4096行相当) なのに、損失は基準と 0.005 以内で同じ。傾きも変わらない。
- 行が独立して育つことが傾きを寝かせている、という仮説は支持されなかった。
- むしろ、Val の層そのものがほとんど効いていない可能性がある (未検証: L=0 の比較が必要)。
- 費用 2.24 ユニット。

## 夜間の一括実験 (d=128, L4 n256, 同じ評価位置 eval_seed=777)

基準: 6M 単独 7.2538 / 混合 6.0267、 24M 単独 6.8067 / 混合 5.9369。

| 構成 | 6M 単独 | 6M 混合 | 24M 単独 | 24M 混合 |
|---|---|---|---|---|
| hng=21 (直前2・3語のハッシュ表) | 7.1711 (-0.083) | 6.0293 (+0.003) | 6.6869 (-0.120) | 5.9325 (-0.004) |
| L=0 (層なし) | 7.3706 (+0.117) | 6.0446 (+0.018) | 6.9929 (+0.186) | 5.9794 (+0.043) |
| 部品1(平均)を外す | 7.2699 (+0.016) | 6.0315 (+0.005) | | |
| 部品2(稀な語の枠)を外す | 7.2736 (+0.020) | 6.0338 (+0.007) | | |
| ctxv を外す | 7.2656 (+0.012) | 6.0285 (+0.002) | | |
| 部品3(キャッシュ)を外す | 実行失敗 (feats に 3 がないと Net.Ek が無く落ちる。 未修正) | | | |

- hng は網の単独を 0.08〜0.12 bit 良くするが、n-gram と混ぜると差はほぼ消える (n-gram と同じ情報)。 単独の傾きは 0.224 → 0.242。
- 層は 6M で単独 0.117、 24M で 0.186 の得。 データが増えると層の寄与が増える (L=0 の傾き 0.189 対 L=4 の 0.224)。 混合では 0.018 → 0.043。
- 入力部品1・2・ctxv は、 6M では それぞれ 0.02 bit 以下しか効いていない。

## 保存済み d512 の診断 (CPU, 500 位置, 単独 6.117 bit)
- Val 層の出力を 0 にすると +0.844 bit (学習し直さない除去なので、 過大に出る)。
- 使われた行 (500位置 x 4行 = 2000 引きのうち): 層0 197行 (上位10行が 65.8%)、 層1 881、 層2 673、 層3 913。 ルーティングが少数の行に偏っている (標本が小さいので、 使用行の総数は下限)。
- val の平均 3.825 バイト/語。 bit/バイト: 網単独(24M d128) 1.779, n-gram 1.656, 混合 1.552。

## bal=0.05 (ルーティングの偏りをならす補助損失, d=128)
6M 単独 7.2941 (+0.040) / 混合 6.0355 (+0.009)。 24M 単独 6.8123 (+0.006) / 混合 5.9470 (+0.010)。 基準より わずかに悪い。 係数は 0.05 の1点だけ。
